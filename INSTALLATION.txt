════════════════════════════════════════════════════════════════════════════════

QUICK INSTALLATION (5 minutes total)
════════════════════════════════════════════════════════════════════════════════

STEP 1: Extract Archive (1 minute)
────────────────────────────────────────────────────────────────────────────────
$ cd /tmp
$ tar -xzf omp-enhanced-v2.0.0-FINAL-COMPLETE.tar.gz
$ cd omp-enhanced

STEP 2: Run Installer (2 minutes)
────────────────────────────────────────────────────────────────────────────────
$ ./install.sh

The installer will:
  • Copy skills to ~/.hermes/skills/
  • Set up skill categories
  • Verify installation
  • Display success message

STEP 3: Verify Skills (30 seconds)
────────────────────────────────────────────────────────────────────────────────
$ hermes skills list | wc -l

Expected output: 126

$ hermes skill view apk-modding-workflow

Expected: Complete SKILL.md content displayed

STEP 4: Deploy LTX-QUASAR (1 minute)
────────────────────────────────────────────────────────────────────────────────
$ cp AGENTS.md ~/.hermes/profiles/umi2/agents/

OR load AGENTS.md content as system prompt in your AI platform

STEP 5: Test Integration (30 seconds)
────────────────────────────────────────────────────────────────────────────────
Test auto-skill loading:
  Request: "Mod this APK to bypass premium"
  Expected: apk-modding-workflow skill auto-loads

════════════════════════════════════════════════════════════════════════════════
TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════════════

Problem: install.sh permission denied
Solution: $ chmod +x install.sh && ./install.sh

Problem: Skills not showing up
Solution: $ hermes skills refresh

Problem: AGENTS.md not loading
Solution: Verify path ~/.hermes/profiles/umi2/agents/ exists
          Or load content as system prompt directly

Problem: Skill loading fails
Solution: Check skill path with: ls ~/.hermes/skills/
          Verify SKILL.md files present
