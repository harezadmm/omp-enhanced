INSTALLATION
------------

```bash
# Extract
tar -xzf omp-enhanced-standalone-fixed.tar.gz
cd omp-enhanced-standalone-fixed

# Install (no root!)
bash install_fixed.sh
```

TROUBLESHOOTING
---------------

Q: "Skills directory not found"
A: Run dari directory yang ada folder skills/

Q: "Permission denied"
A: Jangan pakai sudo/root, run sebagai user biasa

Q: Skills count = 0
A: Extract tar.gz dulu sebelum run installer
