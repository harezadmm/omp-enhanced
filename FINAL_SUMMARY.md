## 🎯 Usage Quick Start

### Install
```bash
cd /tmp/omp-enhanced
./install.sh
find ~/omp-skills -name "SKILL.md" | wc -l  # Verify 126 skills
```

### Use with LTX-QUASAR
```bash
# Deploy AGENTS.md as system prompt
cp AGENTS.md ~/.hermes/profiles/umi2/agents/

# Skills auto-load on task match
# Example: "Mod this APK" → loads apk-modding-workflow
# Example: "Test for SQLi" → loads sqlmap
```

### Browse Skills
```bash
# List all skills
ls ~/omp-skills/

# View specific skill
hermes skill view apk-modding-workflow

# By category
ls ~/omp-skills/ --category security
```
