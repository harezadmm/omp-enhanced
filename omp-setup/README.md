# OMP Skills Setup - Universal Hermes Agent Skills Package

**103 Professional Skills** untuk Hermes Agent dalam satu package all-in-one.

## 📦 Isi Package

- **all_skills.json** (5.18 MB) - 103 skills lengkap dengan content, scripts, templates
- **omp_installer.py** - Installer otomatis ke Hermes Agent
- **convert_skills_to_omp.py** - Source converter (backup)

## 🚀 Cara Install

### Install ke Profile Default
```bash
cd /root/omp-setup
python3 omp_installer.py
```

### Install ke Profile Tertentu
```bash
python3 omp_installer.py umi2
```
